## 数据库层代码梳理（应"帮我掌握数据库代码"）

通读并讲解 NCS 项目数据库层，核心结构：

- **分层**：main.cpp → `PlatformService`（业务 SQL）→ `DatabaseManager`（单例连接）→ `schema.sql`（Qt 资源）→ SQLite 文件 `charge_platform.db`（GenericDataLocation/NCS 下）。
- **DatabaseManager**（core/database/）：单例，open 时开 `WAL` + `foreign_keys=ON`，封装 begin/commit/rollback。
- **PlatformService**（core/service/）：纯静态类，全部业务 SQL。`initialize()` 自举建库/迁移/播种。
- **schema.sql**（core/db/）：9 张表。经 `qt_add_resources(PREFIX "/" BASE core)` 嵌入为 `:/db/schema.sql`，`execSchemaScript` 按 `;` 切分执行、过滤 `--` 注释。
- **版本管理**：`schema_version` 表 + `kSchemaVersion=1`；旧库走 `migrateV0ToV1`（SQLite 加外键需重建表：RENAME→建新→INSERT SELECT→DROP，先 `PRAGMA foreign_keys=OFF`）。
- **外键规则**：RESTRICT（station→charger、user→order、user→recharge_log）；CASCADE（charger→order、charger→ops_log、station→load_prediction）。
- **状态枚举**：charger 0空闲/1使用/2故障；order 0预约/1充电/2完成/3取消；user 1正常/0冻结。
- **关键模式**：`reserve` 用 `UPDATE ... WHERE status=0` + `numRowsAffected()==1` 做乐观锁抢占；`settle` 事务内扣费+更新桩+写订单；聚合查询用 `CASE WHEN` 条件计数；全部 SQL 参数化防注入。
- 密码：`SHA256(salt + 明文)`，种子 admin/123456，盐 ncs-salt。
