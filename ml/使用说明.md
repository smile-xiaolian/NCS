# 机器学习使用说明

对应需求 UC-M-01 ~ UC-M-04。本模块用小时充电量训练 `RandomForestRegressor`，预测各电站未来 24 小时负荷，并把结果交给 Web 大屏和管理端。

当前可以没有真实数据：`ml/dataset/hourly_load.csv` 只保留表头即可，脚本不会因此报错。

---

## 1. 环境

在项目根目录执行：

```bash
pip install -r ml/requirements.txt
```

依赖：`scikit-learn`、`numpy`、`joblib`。Python 建议 3.10。

Windows 与 Ubuntu 命令相同；下文用 `python`，Ubuntu 可换成 `python3`。

---

## 2. 目录

```
ml/
  predict.py                 # 主入口：--train / --evaluate / --predict
  train.py                   # 等价于 predict.py --train
  dataset/hourly_load.csv    # 小时负荷训练集（可为空表头）
  dataset/hourly_load.schema.json
  dataset/holidays.csv       # 节假日，可按年追加
  models/load_rf.pkl         # 训练后生成，不要手改
```

大屏读取的预测文件：`web/public/data/prediction.json`。

---

## 3. 数据集格式

文件：`ml/dataset/hourly_load.csv`

一行表示**一个电站在某一个小时**的充电量合计（度）。

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| `station_id` | 是 | 电站 ID，与数据库 `station.id` 一致 |
| `station_name` | 否 | 站名，给大屏标注用 |
| `datetime` | 是 | `yyyy-MM-dd HH:mm:ss`，建议整点，如 `2026-09-04 18:00:00` |
| `energy` | 是 | 该小时已完成订单的充电量（kWh） |

可选列：`temp_c`（气温）、`is_rain`（0/1）。不填时脚本按日期、小时做确定性模拟。

示例：

```csv
station_id,station_name,datetime,energy
1,天河体育中心站,2026-09-04 18:00:00,42.5
1,天河体育中心站,2026-09-04 19:00:00,38.0
```

约定：

- 同一电站同一小时只写一行。
- 缺某个小时可以不写；从数据库导出时，脚本会把中间缺测小时按 0 补齐。
- 完整列定义见 `dataset/hourly_load.schema.json`。
- 节假日在 `dataset/holidays.csv`，列是 `date,name`。

脚本还会自动生成这些特征：小时、星期、是否周末、是否节假日、近 1/24/168 小时滞后负荷、滑动均值、电站编码。标签是该小时 `energy`。

训练至少需要 **10** 条有效样本，少于此数会跳过训练并写出空预测文件。

## 4. 常用命令

在**项目根目录**执行。

### 4.1 只有 CSV、没有数据库

先把小时数据写入 `ml/dataset/hourly_load.csv`，再：

```bash
python ml/predict.py --train --evaluate --predict
```

只训练：

```bash
python ml/train.py
```

只预测（已有 `ml/models/load_rf.pkl`）：

```bash
python ml/predict.py --predict
```

### 4.2 有 SQLite 数据库

从 `charging_order` 按 `(电站, 小时)` 导出 CSV，再训练、评估、预测：

```bash
python ml/predict.py --db <charge_platform.db 的绝对路径> --export-dataset --train --evaluate --predict
```

Linux 默认库路径示例：

```bash
python ml/predict.py --db ~/.local/share/NCS/charge_platform.db --export-dataset --train --evaluate --predict
```

Windows 库一般在本机 AppData 下的 `NCS` 目录。也可只导出、不训练：

```bash
python ml/predict.py --db <db> --export-dataset
```

带 `--db` 且预测成功时，还会回写数据库表 `load_prediction`。

### 4.3 参数

| 参数 | 作用 |
| --- | --- |
| `--train` | 训练并保存 `ml/models/load_rf.pkl` |
| `--evaluate` | 打印 MAE、RMSE、MAPE，并与「上周同一时刻」基线对比 |
| `--predict` | 预测未来 24 小时，写入大屏 JSON |
| `--export-dataset` | 从数据库导出 `hourly_load.csv`，必须同时给 `--db` |
| `--db` | SQLite 路径，可选 |
| `--dataset` | 自定义 CSV 路径，默认 `ml/dataset/hourly_load.csv` |
| `--holidays` | 自定义节假日 CSV |
| `--model` | 自定义模型路径 |
| `--web-out` | 自定义大屏 JSON 路径，默认 `web/public/data/prediction.json` |

至少指定 `--train`、`--evaluate`、`--predict`、`--export-dataset` 之一。

---

## 5. 输出与大屏对接

`--predict` 默认写入：

`web/public/data/prediction.json`

大屏右侧「未来 24 小时负荷预测」每小时读取该文件：

- `status` 为 `ok` 且 `series` 非空：画模型曲线，高峰标红；若有 `history` 则对比近 24 小时实际负荷。
- 训练集为空或样本不足：`status` 为 `empty`，`series` 为 `[]`，大屏显示占位说明，不画假数据。

把运营侧 JSON 放到 `web/public/data/dashboard.json` 后启动大屏：

```bash
cd web
npm install
npm run dev
```

浏览器打开提示的本地地址（一般为 `http://localhost:5173/`）。

---

## 6. 评估指标

`--evaluate` 会打印类似：

```text
MAE=... RMSE=... MAPE=...%, 上周同刻基线 MAE=...（优于基线 / 未优于基线）
```

指标同时写入 `prediction.json` 的 `metrics`。说明书要求模型优于「用上周同一时刻当预测」的朴素基线；样本太少时会提示跳过评估。

随机种子固定为 `42`，便于复现。

---

## 7. 常见情况

| 情况 | 处理 |
| --- | --- |
| CSV 只有表头 | 脚本正常退出，写出空的 `prediction.json` |
| 样本少于 10 条 | 不训练，提示样本不足 |
| 未安装依赖 | `pip install -r ml/requirements.txt` |
| 大屏仍显示「训练集为空」 | 先写入足够 CSV 或从数据库导出，再跑 `--train --predict`，然后刷新大屏 |
| 想换节假日 | 编辑 `ml/dataset/holidays.csv` 后重新训练 |
